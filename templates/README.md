# AI Interview Trainer Agent

## Project Overview
AI Interview Trainer Agent is an AI-powered system that helps students prepare for interviews by generating role-specific interview questions.

## Features
- Job Role Based Questions
- Skill Based Questions
- Interactive User Interface
- Interview Preparation Support

## Technology Used
- Python
- Flask
- LangFlow (Planned Integration)
- IBM watsonx.ai
- IBM Granite Models
